File explorer harness

Drives ui/files.js against either the real FileApi (when the host exposes one) or the mock file system built into this page. The mock exists for one reason: the bench has no USB stick plugged in and no host bridge wired up yet, so the removable-drive path, the eject path and a 10,000-entry folder can still be exercised on screen. Everything the mock returns is shaped exactly like FileApi's envelope — {ok:true,data} / {ok:false,error,detail}.
Add ?auto=1 to run the whole suite on load and post every line to the host log.
